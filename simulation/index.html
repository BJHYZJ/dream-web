From instruction to released placement

Cross-room dynamic pick-and-place

The robot starts without an observed map, scans and explores. Only after a verified visual discovery does the environment move the target. Subsequent observations trigger stale-memory updates and rediscovery. After grasping, the robot searches for the instructed receptacle while retaining its memory.

Reproduce the demonstrations

Run the corresponding task

The simulation branch is independent of the original ROS hardware workflow. After the documented environment and asset setup, the unified entrypoint launches learned perception and closed-loop control from the exact versioned profile corresponding to each case.

python -m dream_sim.run --preflight
python -m dream_sim.run --case 01 --output results/my_case01
python -m dream_sim.run --all --output results/my_ten_cases

Ten selected cross-room dynamic pick-and-place demonstrations in simulation. Reproduction instructions and scene details are available in our code repository. Each video number corresponds to the same numbered reproduction profile.

What these demonstrations show, and what is adapted

These are development-selected executed examples, not a benchmark or an outdoor evaluation. Full provenance and evaluation records are maintained in the code repository.

The adapter reuses DREAM's learned semantic voxel memory and A* logic. Simulator odometry replaces the physical SLAM backend, language parsing uses a bounded grammar, and hosted mLLM verification is disabled. Grasp/place poses come from current RGB-D geometry and are executed using feedback-controlled motion templates; this is not AnyGrasp or a learned grasp policy. Robot paths are not prerecorded commands.

Video 05 retains its original score and the documented evaluator correction. Videos 07 and 10 use spectator-only views rendered by independently re-executing the same saved controls; these camera changes are not additional learned-policy trials. Their observation and memory panels remain tied to the original run. The code records these distinctions and retains the separate evaluation evidence.
