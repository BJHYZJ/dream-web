Cross-room pick-and-place results

Both memory modes use the same controller and task settings. The object is relocated after its first discovery; the robot must find it again and complete a stable placement in another room. All 60 attempts contribute to the rates above, and each of the 36 successful runs passed independent physical replay and record checks.
