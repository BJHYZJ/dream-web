Residential Evaluation

The recorded controller in 50 development houses, with native-scale objects. All completed tasks pass independent physics, observation, contact, and arm-return checks.

Task completion
38 / 50 (76%); 12 unsuccessful trials
Environment
50 residential scenes used during controller development
Task objects

Action budget
1800 seconds per task

All tasks use seed 42 and dynamic memory, with no fixed server execution deadline. The 12 failures remain in the denominator. These houses were used during controller development; this rate describes the evaluated cohort shown in the recordings below.

Protocol and original recordsDownload results JSON
Why 12 tasks did not complete

Four stopped during pickup search or navigation, two during placement search or navigation, and two reached the 1800-second action budget while searching for a placement location. Two more appear to have reached the navigation iteration limit; this interpretation remains provisional. One release did not satisfy stable placement, and one grasp-alignment failure was followed by unsuccessful empty-arm recovery.

These explanations come from recorded events and evaluator measurements. A search failure does not prove that no physical route exists. Read the failure evidence.

A Long Search for the Placement Container

Case 07 · ProcTHOR-Train-1402 · candle · seed 42

The robot completed this cross-room task after 78.7 minutes of robot-action time and 264.6 m of travel. Finding the placement container accounted for 75.2 minutes (95.5% of the action time). The recorded object remained stably placed for 32.5 seconds, and independent physics, observation and both arm-return checks passed.

Case 07 · Complete extended search78.7 min robot time · 24× playbackView videoClose video
Grasp and loaded arm return · 1× Placement and empty arm return · 1× All four follow-up outcomes

This is a separate follow-up to four cases stopped by action or navigation-iteration limits. Those two limits were removed; goal selection and manipulation rules were retained. Cases 07 and 30 were repeated with a 16 GiB worker cap after their initial 10 GiB attempts reached the memory guard. Original results are preserved. The main evaluation remains 38/50 (76%).

What happened in all four extended searches
Selected follow-up cases; one qualified completion
Case Robot time Outcome
05 71.4 min Lift and stable placement recorded, but cross-room criteria not met.
07 78.7 min Completed; independent task and arm-return checks passed.
30 42.3 min Lift and transport recorded; no stable released placement.
32 42.4 min Requested-target pickup, lift and held transport not verified.

More time enabled one completion but did not resolve the other failures. Case 07 illustrates the travel and search cost that can remain after a successful pickup. Robot-action time excludes inference and loading waits; this simulation does not measure physical battery consumption or establish real-robot multi-room reliability.
