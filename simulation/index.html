Watch Videos Simulation Code Evaluation

Language-guided tasks

Cross-room dynamic pick-and-place

The robot explores each house from a language instruction. The target is moved after the robot first finds it. The robot then updates its memory, finds the object again, and delivers it to the requested plate or bowl.

How to read the videos. Left: external simulator view. Upper right: current head-camera observation. Lower right: observed semantic memory and navigation map; blue shows traveled motion and green shows the planned A* route. Videos play at 4× speed; the clock shows simulation time.
